Generate Python code that calls the Atlas Cloud Workflow API end-to-end.

All requests require `Authorization: Bearer <API_KEY>`. Create the key on the "API Keys" page in the Atlas Cloud console.

## Endpoints
- Inference base:    https://api.atlascloud.ai/api/v1
- Console base (assets): https://console.atlascloud.ai/api/v1

## Full end-to-end flow (Python, runnable)
```python
import os, time, requests

API_KEY = os.environ["ATLAS_API_KEY"]
BASE    = "https://api.atlascloud.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"}

# 1) (optional) fetch the workflow schema to see parameters / defaults
schema = requests.get(f"{BASE}/workflows/seedance-2.0-fast-reference-to-video-workflow", headers=HEADERS).json()["data"]
print(schema["input_schema"].keys())

# 2) submit generation task
body = {"model":"atlascloud/workflow/seedance-2.0-fast/reference-to-video","duration":5,"resolution":"720p","ratio":"16:9","generate_audio":true,"watermark":false,"return_last_frame":false,"reference_images":["https://static.atlascloud.ai/media/images/cd068a5d0bb9f049b56b29c7bfa47b4c.jpg"],"prompt":"A sailboat gently floating on a calm ocean, barely moving with the soft waves. The camera slowly pushes in from a distance, capturing the peaceful scene. Sunlight reflects off the water, creating subtle shimmering highlights. The sail moves slightly in the breeze. Cinematic lighting, soft color tones, shallow depth of field, ultra-realistic textures, 35mm film look, tranquil and atmospheric mood."}
task = requests.post(f"{BASE}/model/generateVideo", headers=HEADERS, json=body).json()["data"]
task_id = task["id"]

# 3) poll until completed
while True:
    r = requests.get(f"{BASE}/model/prediction/{task_id}", headers=HEADERS).json()["data"]
    status = r["status"]
    if status in ("completed", "succeeded"):
        print("video:", r["outputs"][0])
        break
    if status == "failed":
        raise RuntimeError(r.get("error") or r.get("message"))
    time.sleep(3)
```

## Asset Library (optional — only when reusing a subject reference across multiple videos)
Base: `https://console.atlascloud.ai/api/v1`, same `Authorization: Bearer <key>` header.
1. Upload:  POST /sd/assets     body: {"url":"<image_url>","name":"<name>"} → returns { id, atlas_asset_id, status: "Processing" }
2. Poll:    GET  /sd/assets/:id → wait until status === "Active"
3. Use:     pass "asset://<atlas_asset_id>" in any image field (image / last_image / reference_images[*])
Other endpoints: list GET /sd/assets · rename PUT /sd/assets/:id · trash DELETE /sd/assets/:id · restore POST /sd/assets/:id/restore
Image requirements: JPEG/PNG/WebP/BMP, 300–6000 px per side, aspect ratio 0.4–2.5, max 30 MB.
